# Инструкция по запуску Admin Panel

## Предварительные требования

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Примените миграцию базы данных:
```bash
# Подключитесь к PostgreSQL и выполните:
psql -U postgres -d greek_bot -f migrations/001_add_premium.sql
```

Или выполните SQL напрямую в вашей базе данных:
```sql
ALTER TABLE users ADD COLUMN IF NOT EXISTS is_premium BOOLEAN DEFAULT FALSE;
ALTER TABLE users ADD COLUMN IF NOT EXISTS daily_generation_count INT DEFAULT 0;
ALTER TABLE users ADD COLUMN IF NOT EXISTS last_generation_reset TIMESTAMP DEFAULT NOW();
```

## Запуск Admin Panel

Запустите админ-панель командой:
```bash
python run_admin.py
```

Админ-панель будет доступна по адресу: **http://localhost:8000**

## Функциональность

### 1. Статистика
- Общее количество пользователей
- Количество Premium пользователей
- Предложений сгенерировано сегодня
- Активные пользователи за последние 7 дней

### 2. Управление пользователями
- Просмотр всех пользователей
- Поиск по имени, username или ID
- Фильтрация по статусу (все/premium/обычные)
- Переключение Premium статуса
- Просмотр статистики использования каждого пользователя

### 3. Лимиты генераций
- **Обычные пользователи**: 3 генерации предложений в день
- **Premium пользователи**: безлимитные генерации
- Счетчик автоматически сбрасывается каждый день в полночь
